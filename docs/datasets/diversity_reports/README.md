## Score Interpretation

- **≥90**: Excellent diversity — cleared for training
- **70-89**: Good — cleared for training with minor monitoring
- **<70**: Insufficient — remediation required before training

## Report Sections

Each DDR contains 7 sections:

1. Wild Condition Coverage Matrix
2. 14-Dimension Diversity Scores
3. Label Quality Audit
4. OOD Leakage Check
5. Statistical Diversity Tests (chi-square + KS)
6. Overall Diversity Score (0-100)
7. Multi-Model Consensus Review (5 models)
