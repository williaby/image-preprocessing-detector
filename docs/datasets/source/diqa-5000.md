##### 2.4 Provided Metadata

| Metadata Type | Location | Content |
|---------------|----------|---------|
| **Dataset-level** | arXiv paper | Methodology, citation, annotation protocol |
| **Image-level** | CSV columns | MOS scores (3 dimensions), original image reference |
| **Annotation-level** | CSV implicit | 15-subject consensus (aggregated as MOS) |

##### 2.5 Annotation Schema Details

> **Format**: CSV with MOS scores linking enhanced images to originals

**CSV Schema** (train.csv, val.csv, test.csv):

```csv
res,ori,overall,sharpness,color_fidelity
enhanced_001.jpg,original_001.jpg,3.8,4.1,3.5
enhanced_002.jpg,original_001.jpg,4.2,4.5,3.9
```

**Key Fields for Parsing**:

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `res` | str | Yes | Enhanced image filename (what we process) |
| `ori` | str | Yes | Original distorted image reference |
| `overall` | float | Yes | Overall quality MOS (1-5 scale, higher = better) |
| `sharpness` | float | Yes | Sharpness MOS (1-5 scale) |
| `color_fidelity` | float | Yes | Color fidelity MOS (1-5 scale) |

**MOS Scale**: 1 (poor) to 5 (excellent), collected from 15 subjects per image

#### IQA Profile

| Aspect | Assessment |
|--------|------------|
| **Source Type** | Real-world documents with applied enhancements |
| **Key Value** | Gold standard for IQA model calibration |
| **Annotation Quality** | 15-subject consensus per image, 3-dimensional ratings |

#### Benchmark Performance (IQA Models)

| Model | SRCC (avg) | PLCC (avg) | Notes |
|-------|------------|------------|-------|
| **DocIQ** | **0.8704** | **0.8999** | State-of-the-art (2025) |
| DeQA-Doc | 0.847 | 0.878 | VQualA 2025 baseline |
| CLIP-IQA | 0.723 | 0.751 | Zero-shot baseline |

*Metrics: SRCC = Spearman Rank Correlation, PLCC = Pearson Linear Correlation*

#### Training Value

- **Strengths**: Human MOS scores (3 dimensions), 15-subject consensus, diverse distortions, calibration gold standard
- **Weaknesses**: Enhancement-based generation (not purely natural captures), MOS only (no variance annotations)
- **Critical**: **NEVER train on this dataset - benchmark only**
