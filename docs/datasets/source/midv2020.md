##### Annotation Format

Annotations use **VIA (VGG Image Annotator v2)** format. One JSON file per document type covers all 100 images for that type.

```text
extracted/{mode}/annotations/{doc_type_code}.json
```

VIA structure (abbreviated):

```json
{
  "_via_img_metadata": {
    "05.jpg<size>": {
      "filename": "05.jpg",
      "regions": [
        {
          "shape_attributes": {
            "name": "polygon",
            "all_points_x": [x0, x1, x2, x3],
            "all_points_y": [y0, y1, y2, y3]
          },
          "region_attributes": { "type": "document_quad" }
        }
      ]
    }
  }
}
```

- One `regions` entry per visible field + one for the document boundary quad
- Field text values (names, dates, document numbers) embedded in `region_attributes`
- Script varies by document type: Cyrillic (`rus`, `srb`), Greek (`grc`), Latin (all others)

### 13.3 Corpus Role & Constraints

MIDV-2020 provides the only **paired camera + flatbed scanner** captures in the training corpus, making it uniquely valuable for `capture_method_cls` head training: ~1K camera stills across 8 controlled conditions (projective distortion, low lighting, highlight, backgrounds) paired with ~3K high-quality flatbed scans of the same 10 document types. It is also the **sole Greek script (Grek) source** in the corpus (400 samples from `grc_passport`) and supplements Cyrillic coverage from MIDV-500. Orientation labels are derived from the `scan_rotated` archive (rotation class from archive name).
