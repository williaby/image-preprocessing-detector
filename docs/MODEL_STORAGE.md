This document describes the end-to-end workflow for storing, versioning, and promoting machine learning model artifacts for the Image Preprocessing Detector project.

## Overview

The artifact management system follows three core principles:

1. **GCS is the canonical, complete artifact archive**
   - Every Modal training run saves ALL artifacts to Google Cloud Storage
   - Structured directory hierarchy with immutable runs
   - Complete reproducibility metadata

2. **Hugging Face Hub is the curated release registry**
   - Only validated, production-ready models
   - Semantic versioning (v1.0.0, v1.1.0, etc.)
   - Clean model cards and documentation

3. **Promotion from GCS → HF is explicit and manual**
   - Training never pushes directly to HF
   - Promotion reserved for project leads
   - Quality gates and validation required

## GCS Directory Structure

```text
gs://rag-pipeline-models/
  image-preprocessing-detector/
    resnet50_teacher/
      runs/

          dataset_version.txt
          env_info.txt
    resnet18_student/
      runs/
        2025-11-15T02-05Z_run-def456/
          ...
```text

### Required Artifacts Per Run

Every training run MUST include these files:

| File | Description | Generated By |
|------|-------------|--------------|
| `model_final.pth` | Best checkpoint or final epoch | Training script |
| `training_config.yaml` | Hyperparameters, architecture, etc. | `generate_training_config_file()` |
| `metrics.json` | Loss curves, accuracy, eval metrics | `generate_metrics_file()` |
| `commit_hash.txt` | Git commit, branch, status | `generate_commit_hash_file()` |
| `dataset_version.txt` | Dataset version/hash | `generate_dataset_version_file()` |
| `env_info.txt` | Python, CUDA, library versions | `generate_env_info_file()` |

Optional artifacts:

- `model_epoch_XX.pth` - Intermediate checkpoints
- `best_model.onnx` - ONNX export for inference
- `tensorboard/` - TensorBoard logs
- `plots/` - Training curves, confusion matrices

## Training Workflow (Modal)

### 1. Setup Training Script

Import the utilities:

```python
from image_preprocessing_detector.utils import (
    generate_run_metadata,
    generate_run_id,
    upload_run_to_gcs,
)
```text

### 2. Generate Run ID

At the start of training:

```python
run_id = generate_run_id(prefix="resnet50-teacher")
# Example: "2025-11-15T01-20Z_resnet50-teacher-a1b2c3"

output_dir = "/root/output"
os.makedirs(output_dir, exist_ok=True)
```text

### 3. Train Model

Save checkpoints to `output_dir`:

```python
# During training
torch.save(model.state_dict(), f"{output_dir}/model_epoch_{epoch}.pth")

# Final checkpoint
torch.save(model.state_dict(), f"{output_dir}/model_final.pth")
```text

### 4. Generate Metadata

After training completes:

```python
# Training configuration
config = {
    "model": {
        "architecture": "resnet50",
        "pretrained": True,
        "num_classes": 4,
        "input_size": 224,
    },
    "training": {
        "batch_size": 128,
        "epochs": 100,
        "learning_rate": 0.001,
        "optimizer": "Adam",
    },
}

# Evaluation metrics
metrics = {
    "final_train_loss": 0.15,
    "final_val_loss": 0.18,
    "val_accuracy": 0.92,
    "val_macro_f1": 0.91,
    "best_epoch": 87,
    "total_epochs": 100,
    "training_time_seconds": 3600,
}

# Generate all metadata files
generate_run_metadata(
    output_dir=output_dir,
    config=config,
    dataset_version="v1.2.0",
    metrics=metrics,
    dataset_info={
        "num_train_samples": 35000,
        "num_val_samples": 5000,
        "labels": ["blur", "skew", "contrast", "noise"],
    },
)
```text

### 5. Upload to GCS

```python
from image_preprocessing_detector.utils import upload_run_to_gcs

gcs_path = upload_run_to_gcs(
    local_dir=output_dir,
    bucket_name="rag-pipeline-models",
    project_name="image-preprocessing-detector",
    model_name="resnet50_teacher",
    run_id=run_id,
)

print(f"Artifacts uploaded to: {gcs_path}")
```text

## Promotion Workflow (GCS → Hugging Face Hub)

### Prerequisites

1. **HF Token**: Set `HF_TOKEN` environment variable

   ```bash
   export HF_TOKEN=your_huggingface_token
   ```

1. **GCS Access**: Ensure `GOOGLE_APPLICATION_CREDENTIALS` is set

   ```bash
   export GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account-key.json
   ```

### List Available Runs

```bash
python scripts/promote_to_hf.py \
  --list-runs \
  --gcs-bucket rag-pipeline-models \
  --project image-preprocessing-detector \
  --model resnet50_teacher
```text

### Dry Run (Validation Only)

Test promotion without pushing:

```bash
python scripts/promote_to_hf.py \
  --dry-run \
  --gcs-bucket rag-pipeline-models \
  --project image-preprocessing-detector \
  --model resnet50_teacher \
  --run-id 2025-11-15T01-20Z_run-abc123 \
  --version v1.0.0
```text

### Promote to HF Hub

```bash
python scripts/promote_to_hf.py \
  --gcs-bucket rag-pipeline-models \
  --project image-preprocessing-detector \
  --model resnet50_teacher \
  --run-id 2025-11-15T01-20Z_run-abc123 \
  --hf-repo williaby/doc-preproc-resnet50-teacher \
  --version v1.0.0 \
  --private
```text

The script will:

1. ✅ Download artifacts from GCS
2. ✅ Validate required files exist
3. ✅ Check promotion criteria (metrics, reproducibility)
4. ✅ Generate model card (README.md)
5. ✅ Create/update HF repository
6. ✅ Upload model files and metadata
7. ✅ Create semantic version tag

### Promotion Criteria Checklist

Before promoting a model, verify:

- [ ] **Performance**: Metrics meet or exceed baseline
- [ ] **Reproducibility**: Trained from clean git state (not dirty)
- [ ] **Completeness**: All required metadata files present
- [ ] **Documentation**: Model purpose and usage clear
- [ ] **Validation**: Tested on held-out evaluation set
- [ ] **Version**: Semantic version assigned (v1.0.0, v1.1.0, etc.)

## Security Considerations

### GCS Service Account

- ✅ Use least-privilege service account
- ✅ Grant only Storage Object Creator/Viewer roles
- ✅ Enable uniform bucket-level access
- ✅ Never commit service account keys to git

### Modal Secrets

Store GCS credentials as base64-encoded secret:

```bash
# Encode service account key
base64 -i /path/to/service-account.json > key.b64

# Create Modal secret
modal secret create gcs-credentials GCP_SA_KEY=@key.b64

# Clean up
rm key.b64
```text

### Hugging Face Token

- ✅ Use fine-grained access token (not classic token)
- ✅ Grant only `write` permission for specific repos
- ✅ Store in GitHub Secrets for CI/CD
- ✅ Never commit to repository

## Versioning Strategy

### Semantic Versioning

Follow [semver.org](https://semver.org) principles:

- **MAJOR** (v1.0.0 → v2.0.0): Incompatible API changes, architecture changes
- **MINOR** (v1.0.0 → v1.1.0): New features, improved performance, backward compatible
- **PATCH** (v1.0.0 → v1.0.1): Bug fixes, minor corrections

### Examples

```text
v1.0.0 – Initial ResNet50 teacher model
v1.1.0 – Improved augmentation pipeline (+2% accuracy)
v1.2.0 – Added ONNX export for CPU inference
v2.0.0 – Switched to EfficientNetV2 architecture (breaking change)
```text

## Troubleshooting

### Upload Fails: Permission Denied

**Solution**: Verify service account has Storage Object Creator role:

```bash
gcloud projects get-iam-policy YOUR_PROJECT_ID \
  --flatten="bindings[].members" \
  --filter="bindings.members:serviceAccount:YOUR_SA_EMAIL"
```text

### HF Push Fails: Authentication Error

**Solution**: Verify HF_TOKEN is set and has write permissions:

```bash
echo $HF_TOKEN  # Should show token
python -c "from huggingface_hub import whoami; print(whoami())"
```text

### Metadata Generation Fails: Not a Git Repository

**Solution**: Ensure code is in a git repository:

```bash
cd /path/to/repo
git rev-parse --git-dir  # Should show .git
```text

### Modal Can't Access GCS

**Solution**: Verify Modal secret exists and is attached:

```bash
modal secret list  # Should show gcs-credentials

# Recreate if needed
./scripts/modal_helpers.sh setup-gcs-secret /path/to/key.json
```text
