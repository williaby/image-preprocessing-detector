**Adequacy Rating (pre-consensus)**: ⚠️ Needs Work

**Analyst Summary**: SIG-G3-2 faces a fundamental measurement paradox: the precision target (< 0.3° MAE) is below the label quality floor for 21% of the training and test data (natural scans at ~0.9° uncertainty). Mathematically, even a perfect model cannot demonstrate the stated target on the current mixed test set — the irreducible label noise contribution from natural scans (0.21 × 0.9° ≈ 0.19°) leaves only 0.11° error budget for the 79% synthetic portion, with zero margin for model generalization error. The dataset is adequate for MNV4-H2's 1.0° MAE target but was not designed for SIG-G3-2's 3× harder precision requirement. Training CAN proceed on the 79% synthetic component (full-resolution SigLIP processing with exact labels provides a strong foundation), but the evaluation strategy is blocked and two training set gaps (warping, near-zero density) must be addressed before training produces a validly-measured precision result.

### Consensus Summary

**Unanimous rating: NEEDS WORK** (both models, confidence 9/10).

**Key consensus findings:**

**Q1 — Is MAE < 0.3° achievable and verifiable?**
Both models agree: the target is likely achievable by SigLIP 2 architecture on the SYNTHETIC subset (full-resolution processing provides sufficient spatial information), but is **not verifiable on the current mixed test set**. The ~0.19° baseline MAE contribution from natural scan label noise leaves effectively zero margin for model generalization error. Achieving a measured MAE < 0.3° on the current test set would require near-perfect synthetic performance AND favorable noise cancellation in the natural subset — statistically improbable in practice.

**Q2 — Should target be revised?**
Gemini 2.5 Pro: Revise global target to MAE < 0.5° (pragmatically aligns with proven dataset capabilities).
Gemini 3 Pro Preview: Split the target — Synthetic MAE < 0.1°–0.15°, Natural MAE < 0.7°–0.8°, Global MAE < 0.3° gated on gold-standard test set creation.
Synthesis: Both approaches are sound. The split-target approach is more rigorous and operationally useful. Recommended: adopt split metrics (see SKEW-SIG-G09), retain global < 0.3° as an aspirational target contingent on gold-standard test set.

**Q3 — Does gold-standard label improvement matter?**
Unanimous: **Critically important**, and relabeling the TEST SET is more valuable than relabeling training data. The model can learn precision from the 79% synthetic tier (with Gaussian NLL); what it cannot do is prove it achieved the target without a trusted evaluation ruler. 500–1,000 manually verified natural scan test images to < 0.1° precision would unblock evaluation. Relabeling training data (active learning prioritized by model-vs-label disagreement) is a secondary improvement.

**Q4 — Should Gaussian NLL replace SmoothL1?**
Unanimous: **Mandatory.** Gaussian NLL allows the model to predict per-sample uncertainty (μ, σ²), learning to output low uncertainty on synthetic (exact labels) and high uncertainty on natural (noisy labels). This prevents noisy natural scan gradients from corrupting the precision features learned from the synthetic tier. Standard SmoothL1 treats all labels equally, causing gradient pollution that limits peak precision. The `label_noise_tier` field (0.0 for synthetic, 0.9 for natural) should be added to the manifest to seed σ priors.

**Q5 — Most critical dataset gap?**
Both models identify two co-equal P0 gaps:
