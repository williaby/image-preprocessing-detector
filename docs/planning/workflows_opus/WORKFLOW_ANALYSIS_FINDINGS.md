**Schema (Field Exists)**:

| Risk | Severity | Description |

| Developer confusion | MEDIUM | Unclear implementation guidance |
| Test maintenance | MEDIUM | Tests exist for "deferred" functionality |
| Architectural drift | HIGH | Production plan diverges from ADR decisions |

### Recommended Resolution

**Option A: Remove from Production Scope**

1. Update `PROJECT_PLAN.md` to remove Hybrid IQA from Light Layout
2. Add deprecation warning to `quality_issues` field
3. Move per-element tests to `tests/research/` directory
4. Update ADR-029 as authoritative scope document

**Option B: Include in Production Scope**

1. Update `project-a-project-plan.md` to move Phase 12.2 to active phase
2. Update ADR-029 to reflect decision change

**Recommendation**: Option A (Remove from Production)

## 5. Consensus Elements (90% Agreement)

All sources agree on these core workflow elements:

### 5.1 Primary Pipeline Flow

```text
Input (PDF/Image)
    ↓
Pre-flight Analysis (DPI detection, upscaling)
    ↓
Ingestion (standardize to 300 DPI)
    ↓
PDF Type Classification (image_only/born_digital/hybrid)
    ↓
Text Gate Routing (<10ms decision)
    ↓
┌─────────────┴─────────────┐
│ NO TEXT      │ TEXT DETECTED │
│ Classical IQA│ Layout-Lite   │
│ (full page)  │ Detection     │
└─────────────┬─────────────┘
              ↓
ML IQA (Student inference)
    ↓
Uncertainty Gate → Teacher (if needed)
    ↓
Corrections (with guardrails)
    ↓
DQS Calculation
    ↓
Routing Recommendation
    ↓
Output (DocumentMetadata.json + images)
    ↓
Project B Handoff
```text

### 5.2 Agreed Performance Targets

| Stage | GPU Target | CPU Target |
|-------|-----------|-----------|
| Pre-flight | <100ms | <100ms |
| DPI Upscaling | 310-360ms/page | 310-360ms/page |
| Text Gate | <10ms | <10ms |
| Classical IQA | <25ms | <25ms |
| Student ML IQA | <10ms | <40ms |
| Teacher ML IQA | <30ms | N/A (GPU only) |
| Corrections | <100ms | <100ms |
| Total (no upscaling) | <150ms/page | <500ms/page |

### 5.3 Agreed Model Architecture

| Model | Architecture | Size | Purpose |
|-------|-------------|------|---------|
| Teacher | ResNet-50 | 105 MB | High-capacity (selective) |
| Student | ResNet-18 | 42 MB | Production default |
| Layout | DocLayout-YOLO | ~50 MB | Element detection |
