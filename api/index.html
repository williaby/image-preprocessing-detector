    API Reference

    API Reference documentation for the Image Preprocessing Detector.

    Modules¶

    image_preprocessing_detector ¶

    Image Preprocessing Detector for RAG Applications.

    An intelligent image preprocessing pipeline that analyzes documents (PDFs, images) and automatically detects required preprocessing steps before vector database ingestion.

    Bases: BaseModel

    Category of the element

    confidence pydantic-field ¶

    Detection confidence

    correction_applied = None pydantic-field ¶

    Details of correction applied to this element

    id pydantic-field ¶

    Unique identifier for this element

    needs_correction = False pydantic-field ¶

    Whether this element requires quality correction

    polygon = None pydantic-field ¶

    Optional polygon points for irregular shapes

    quality_issues pydantic-field ¶

    Quality issues specific to this element (for images)
